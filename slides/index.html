Props: live room data from the node

Four of the Room component's props are bound to fields on the room node, so no one types them in.

Prop Bound to
code the node title (the room code)
status field_status (shown as its label, "Open" or "Closed")
currentSlide field_current_slide
slideTitle field_current_slide_title

Slots: the Room component only does layout

  • Five slots: swarm, slider, requests, comments, recap
  • The template fills each with a child component
  • Each child's code is bound to the node title

Looking up a Room

  • submitCode calls getRoom in lib/fun-room-api.ts
  • A JSON:API query on the room content type, filtered by title (the room code)
  • Drupal API Client available to Canvas out of the box
  • Caching is off: a room can close at any time

Joining

  • The browser generates a random 24-byte hex token. The server stores only its SHA-256 hash
  • Participant token kept in local storage
  • Creates a participant through JSON:API, linked to the room
  • Drupal API Client can handle CRUD operations
  • Redirects to room node path

The room page

  • One content template renders every room
  • Paints from the node's fields, then polls the room every 2 seconds
  • Header: room code, open or closed, and the slide the deck is showing
  • Joined? Your name and avatar. Not yet? A "Join this room" button

Live, then closed

  • Open: the swarm and slider, plus requests and comments. Each polls its own endpoint
  • Closed: the recap replaces the swarm and slider
  • One column on phones, two on wide screens
  • An empty slot renders nothing

The slide deck

  • Reveal.js, built with Vite
  • The sidebar, swarm and recap are small Preact components, styled with Tailwind
  • It runs beside a live sidebar of the room and scales to fit
  • With no site configured, it uses a simulated room and works offline

Talking to the room

  • On every slide change the deck reports the slide's index, id and title
  • A shared presenter key keeps anyone else from moving the room
  • Only the latest slide is sent, and it retries if the site can't be reached
  • The sidebar polls the room for the swarm, mood, comments and requests

The deck follows the room

  • The room's mood sets the background on every slide, with confetti when it hits high
  • Keys fill the screen with one area: S slide, R room, C comments, D recap
  • Esc returns to the split view
